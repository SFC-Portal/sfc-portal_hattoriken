# Claude Code 利用ガイド

## クイックスタート

```bash
cd /path/to/sfc-portal_hattoriken
claude
```

Claudeは自動的に `CLAUDE.md` を読み込み、プロジェクトのコンテキストを理解する。

## プロンプトパターン

### 機能追加

```text
既存のアーキテクチャに従って [機能名] を追加してください
```

### コンポーネント作成

```text
TaskCardコンポーネントを作成してください：
- タスクのタイトル、期限、優先度を表示
- 完了チェックボックス付き
```

### バックエンド実装

```text
[サービス名] サービスのメソッドを実装してください
```

### コードレビュー

```text
TaskServiceの実装に潜在的な問題がないかレビューしてください
```

## 良いプロンプトの書き方

### 悪い例

```text
バグを直してください
```

### 良い例

```text
TaskListコンポーネントでtasks配列が空のときにエラーが表示されます。
空状態のハンドリングを追加してください。
```

### ポイント

1. **具体的なファイルパスを指定** — `frontend/src/components/layout/Navbar.tsx`
2. **期待する動作を明記** — 「未認証ユーザーは/loginにリダイレクト」
3. **既存パターンへの言及** — 「既存のパターンに従って」

## スラッシュコマンド

| コマンド | 説明 |
|---------|-----|
| `/init` | CLAUDE.mdを生成・更新 |
| `/status` | 現在の設定を表示 |
| `/clear` | 会話履歴をクリア |
| `/help` | ヘルプを表示 |

## 自動適用される規約

Claudeは以下を自動的に守る：

- TypeScript strictモード
- 日本語UI文言
- `@/` パスエイリアス
- PascalCaseコンポーネント
- React Queryによるサーバー状態管理
- Tailwind CSSスタイリング

## トラブルシューティング

| 問題 | 解決策 |
|-----|-------|
| プロジェクトを理解しない | `/init` を実行 |
| 誤った想定をする | 具体的なファイルを参照 |
| パターンに従わない | 「既存のパターンに従って」を追加 |
